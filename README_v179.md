# v179 — обновление DM Toolkit

Дата выпуска: 10 ноября 2026 года.

- Консоль временных аномалий приведена к правилам Пирамидки v1.1: установка, непрерывные условия канала, срыв, разрушение и завершение операции. Повторные команды не повторяют учёт хода или награду.
- Подписи максимальных хитов NPC используют вычисляемое значение. Полные тексты способностей раскрываются в карточке; известные типы действий распределены явно.
- Монстры добавляются группами независимых копий. Сцена сохраняет участников, очередь, ход, раунд и поддерживаемые состояния; доступны экспорт, проверяемый импорт и резервная копия.
- Рабочие экраны приспособлены к узкой ширине; каталог открывается отдельно, есть переход к атакам и управление с клавиатуры.
- Единое меню и [обзор DM Toolkit](dm-toolkit.html) помогают выбирать инструменты по задачам. Старые адреса сохранены.

## Сохранения

Схема сцены монстров — v1; контракт описан в [MONSTER_SCENE_FORMAT_v1.md](MONSTER_SCENE_FORMAT_v1.md). Идентификатор набора данных остаётся wot-bestiary-v178: он обозначает каталог, а не номер выпуска сайта.

Консоль аномалий читает прежнее состояние v148 и сохраняет новую операцию в отдельной схеме v179. Старое состояние сохраняется. Перед обновлением активной игры сохраните важные данные; у монстров доступен экспорт сцены. Возврат старого кода не откатывает данные браузера.

## Проверки и границы

Пройдены шесть проверок поведения из tools/, проверка синтаксиса, локальные браузерные сценарии и выбранные проверки размеров/клавиатуры. Масштаб 200% для обзора и трёх консолей подтверждён ручной приёмкой пользователя.

Полный аудит всех статблоков, ресурсов, контраста, средств чтения с экрана и производительности не заявляется. Общая смешанная сцена NPC+монстры в выпуск не входит.
