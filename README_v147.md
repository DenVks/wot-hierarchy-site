# v147 · Монстры временных аномалий в DM Toolkit

Конструктор энкаунтера Аномальной Стены дополнен существами из общего бестиария временных аномалий.

## Состав противников

- Сохранены 9 существ, непосредственно описанных в руководстве Мастера Аномальной Стены.
- Добавлены все 33 монстра из раздела `monsters.html#anomaly-monsters`.
- В списке теперь 42 доступных противника, не считая варианта «Без противников».
- Временные монстры отделены от существ Стены и сгруппированы по R5–R7 и Type A/B/C.
- Каждая временная запись показывает имя, CR, рейтинг и тип аномалии.
- Из конструктора можно перейти к полным карточкам в бестиарии.

## Совместимость

Сцены v146, v145, v144 и v142 автоматически преобразуются в формат v147. Состав, количество противников, Метки и журнал сохраняются.
