# Версия 156 · Сводное сравнение всех Иерархий

- В раздел сравнения добавлена общая таблица, одновременно показывающая все семь Иерархий.
- Таблица строится автоматически из единой базы, поэтому названия, ранги и числовые профили не дублируются вручную.
- Сопоставляются высшие ранги: характеристики, хиты, КД, атака, урон, скорость, инициатива, спасброски, направление и особые ресурсы.

- Для Крика указаны варианты «Счёта витков» и зависимость рангового профиля от настроенного заряда кварца.
- Для Хрустального Трона VI уточнены пределы обычного и уникального NPC.
- Под сводкой сохранено подробное сравнение любых двух выбранных Иерархий и рангов.
