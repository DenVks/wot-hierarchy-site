# v144 · Пошаговый DM Toolkit Аномальной Стены

Пульт мастера перестроен вокруг явного цикла сцены, чтобы во время игры не приходилось каждый раунд заново решать, что проверять.

## Главное изменение

Над состоянием экспедиции появился «режиссёрский цикл» из шести этапов:

1. до сцены;
2. открытие;
3. начало раунда;
4. ходы всех сторон;
5. конец раунда;
6. после сцены.

На каждом этапе показывается короткий рабочий чек-лист. Отмеченные пункты сохраняются локально вместе с остальным состоянием экспедиции.

## Ходы всех сторон

Внутри раунда Toolkit формирует очередь из:

- каждого героя из списка группы;
- противников;
- цели сцены или NPC;
- Стены и таймера.

Для активного участника выводится отдельное окно действий. Нажатие основной кнопки переводит к следующему участнику, затем к концу раунда и следующему раунду.

## Периодичность

- STAB не уменьшается автоматически в бою.
- Удар среды не бросается автоматически каждый раунд.
- Маршрутные проверки остаются в тактах выбранного перехода.
- Для таймера можно явно выбрать периодичность: каждый раунд, раз в 10 раундов, по событию или без таймера.
- Тоннель отдельно напоминает, что 10 раундов равны одной минуте и его таймер не останавливается.

## Совместимость

Состояние из `v142` автоматически переносится в новый локальный формат `v144`. Каркас сцены, группа, маршрут, журнал, STAB и Метки сохраняются.
