# Версия 153 · Единая база Иерархий

## Что изменено

- Создана единая нормализованная база механических профилей семи Иерархий.
- В базу включены 43 ранга и 110 полных записей способностей.
- Иерархия Единства синхронизирована с игроковой редакцией v1.2: ранги I–V, актуальные титулы, числовые профили и способности.
- NPC Generator получает названия, ранги, пути, числовые параметры и способности из общей базы.
- Добавлены Единая Воля Шары, Иерархия Крика и полная Иерархия Аномальной Стены I–VIII.
- Для Единой Воли выбирается Путь Айяд или Путь Воина.
- Исправлен расчёт увеличенных Костей Хитов: множитель применяется только к компоненту Костей Хитов, а модификатор Телосложения добавляется после него.
- На странице Иерархий появился интерактивный инструмент механического сравнения любых двух Иерархий и рангов.
- Старый расчётный список в `npc-rules-data.js` выведен из активного использования и оставлен как архив совместимости.

## Проверки

- В базе: 7 Иерархий, 43 ранга, 110 способностей.
- Проверены уникальность идентификаторов и названий способностей, непрерывность рангов, наличие механического и справочного профиля каждого ранга.
- Проверка целостности базы завершена без ошибок.
- Все изменённые JavaScript-файлы проходят `node --check`.
- NPC Generator и интерактивное сравнение загружаются локально без ошибок выполнения.
