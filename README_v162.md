# v162 — Единый стиль страниц правил

Обновлены страницы `alchemy.html` и `player-rules.html`.

## Что изменено

- Страницы выровнены по общей дизайн-системе сайта: тёмный кодекс, золотые акценты, карточки с общей геометрией, тенями и рамками.
- Восстановлена единая типографическая иерархия:
  - `Marcellus` — названия страниц, глав и крупных разделов;
  - `Cinzel` — рубрики, подразделы, подписи и элементы навигации;
  - `Crimson Pro` — основной текст правил.
- Для `player-rules.html` переработано оглавление: добавлены заголовок, нумерация глав, активное состояние и более удобная адаптивная раскладка.
- Для `alchemy.html` приведены к общему стилю якорная навигация, три смысловые карточки, таблицы, цитаты и внутренние заголовки.
- Добавлены служебные рубрики «Снаряжение и владение» и «Игровая процедура» без изменения или сокращения канонического текста.
- Обновлена мобильная раскладка обеих страниц.

## Проверка

- В браузере загружаются все 3 раздела алхимии; объём отображаемого текста — 14 314 символов, заглушек загрузки нет.
- В справочнике игрока доступны все 7 глав; активная глава содержит 20 670 символов, заглушек загрузки нет.
- Фактически применённые шрифты проверены через браузер: `Marcellus` для `h2/h3`, `Cinzel` для `h4/h6`.
- Выполнена визуальная проверка в настольной и узкой раскладках.
