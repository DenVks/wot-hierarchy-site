# v160 — Традиции Дичка в генераторе NPC

Канонический источник:

- `Дополнение к Книге Игрока 5ed по Колесу Времени_v.2.3_синхронизировано_v16_Глава_6_Регрессии_QA.md`.

Исправлен выбор архетипа для класса «Дичок»:

- поле «Архетип / Традиция» содержит только три Традиции Дичка: «Мудрый», «Странник» и «Сновидец»;
- Исключительные таланты больше не показываются как архетипы и не подменяют Традицию;
- для каждой Традиции добавлены полные классовые черты 3-го, 7-го, 11-го, 15-го и 20-го уровней;
- генератор автоматически добавляет только базовые черты Дичка и черты выбранной Традиции, доступные на текущем уровне;
- ранее сохранённые карточки Дичка с ошибочно выбранным Исключительным талантом переводятся на «Мудрого» с предупреждением о необходимости проверить Традицию и сохранить карточку заново.

Исключительные таланты сохранены в базе правил и в отдельном механизме выбора талантов; из механики Традиций они исключены.
