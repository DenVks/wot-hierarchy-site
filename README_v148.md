# v148 — DM Toolkit временных аномалий

Новая страница `anomaly-dm.html` проводит Мастера через полную узловую операцию без переключения между таблицами:

- паспорт R1–R10, Type A/B/C, размер S1–S6 и подвижность;
- поиск узловой точки по минутам;
- призыв и установка Пирамидки с учётом ранга оператора;
- независимые счётчики Ядра, пульса среды, волны существ и извлечения;
- контроль условий канала и повреждений Пирамидки;
- финальный Замок Узора и таблица последствий провала;
- один бросок артефактного остатка и переход к генератору ингредиентов;
- состав волны из 33 существ временных аномалий, уже находящихся в бестиарии.

Добавлены входы в пульт со страниц `anomalies.html`, `loot-generator.html` и `wall-dm.html`.
