# v180 — библиотека NPC и общая сцена боя

Дата выпуска: 13 ноября 2026 года. Уровень готовности нового общего боя: **готово к плейтесту**.

- Генератор сохраняет несколько независимых NPC в постоянную библиотеку GitHub. Доступны создание, редактирование, сохранение как нового и архивирование.
- «Сохранить и добавить в общую сцену» переносит точную сохранённую карточку в бой без промежуточного JSON. Отдельный переход в прежний «NPC / Бой» остаётся в библиотеке.
- [Общая сцена боя](encounter.html) объединяет NPC и монстров в одной очереди. У каждой копии отдельные хиты, состояния, ресурсы и снимок исходной карточки. Добавлены ячейки, доступные кости превосходства/легендарный ресурс, собственные счётчики, заметки и броски.
- Бой сохраняется в GitHub с участниками, инициативой, текущим ходом и раундом; его можно открыть с другого компьютера. Устаревшее сохранение отклоняется, текущий черновик остаётся во вкладке. Можно создать независимую копию боя.
- Перенос прежних локальных боёв NPC v56 и монстров v1 проходит через просмотр и подтверждение. Источник остаётся на месте, полный исходный снимок сохраняется в новом документе, заменяемая общая сцена резервируется.
- В меню DM Toolkit добавлена общая сцена. Прежние подробные боевые инструменты доступны.

## Подключение и данные

Пароль сайта сохраняется. Отдельной учётной записи приложения и отдельного сервера нет. Интерфейс работает на GitHub Pages, документы — в отдельной ветке `wot-data`: `wot-data/npcs.json` и `wot-data/encounters.json`.

Для начала откройте «Подключить GitHub» в генераторе или общей сцене. По умолчанию используется `DenVks/wot-hierarchy-site`. Для записи нужен fine-grained PAT выбранного репозитория с `Contents: Read and write`. Ключ вводится непосредственно в поле сайта; по умолчанию действует до обновления страницы, с отдельным флажком — в сессии вкладки. Он не включается в карточки, URL, экспорт и код сайта. Публичные данные доступны для чтения без ключа. На другом компьютере выберите то же хранилище и загрузите библиотеку/список боёв.

Ветка публичного репозитория публична; пароль сайта не скрывает файлы GitHub. Для закрытых заметок в существующем окне подключения можно выбрать приватный репозиторий данных. Локальные черновики не синхронизируются между компьютерами: синхронизируется подтверждённая запись GitHub.

Контракты: [библиотека NPC](SHARED_LIBRARY_FORMAT_v1.md), [общая сцена](ENCOUNTER_SCENE_FORMAT_v1.md), [прежняя сцена монстров](MONSTER_SCENE_FORMAT_v1.md). Наборы данных сохраняют свои версии; номер схемы и метка кэша ресурсов не являются номером выпуска сайта.

## Проверки и границы

Пройдены десять наборов автоматических проверок из `tools/`, выбранные браузерные сценарии, адаптивная раскладка и настоящая запись/чтение/конфликты GitHub на синтетических данных. Chrome 200% для генератора, NPC / Бой и новой общей сцены подтверждён ручным PASS пользователя. Физический второй компьютер отдельно не проверялся; независимое чтение без состояния первого браузера проверено API-клиентами.

Общая сцена предоставляет основной смешанный бой. Специальные обработчики предметов, форм, талантов, эликсиров, отдыха и тактических подсказок остаются в прежних инструментах; соответствующие данные при переносе сохраняются. Бонусы текстового правила второй фазы, концентрацию, сопротивления, критические попадания и игровые последствия применяет Мастер. Полная замена всех возможностей прежних инструментов и проверка реальной игровой сессией остаются открытыми.

При восстановлении старого кода документы ветки `wot-data` и новые браузерные ключи не удаляются. v179 не умеет открывать общую сцену v1; возврат кода не является обратной миграцией игровых данных. Нужные сцены можно дополнительно скачать в JSON. Факт развёртывания и проверка доставки выпуска фиксируются отдельным QA в основном корпусе проекта.
