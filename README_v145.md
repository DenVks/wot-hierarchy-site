# v145 · Пояснения DM Toolkit и единый блок пути

DM Toolkit уточнён после проверки реального мастерского сценария.

## Что изменилось

- Каждый из шести пунктов «До сцены» теперь прямо отвечает на два вопроса: «Что сделать?» и «Зачем?».
- Под чек-листом пояснено, что галочка фиксирует принятое решение и сама по себе не требует броска.
- Блок «Маршрут» переименован в «Путь экспедиции · вне инициативы».
- Внутри него добавлена инструкция из трёх шагов: выбрать отрезок, дождаться его окончания, разрешить проверку и перейти дальше.
- Отдельное окно «Режим перехода» удалено как дублирующее.
- Его единственная полезная часть — проверка текущего отрезка — перенесена непосредственно в блок пути.
- Формулировки явно запрещают делать маршрутную проверку каждый раунд боя.

## Когда нужен путь экспедиции

Он используется для часов Ореола, сегментов Окна дрейфа, этапов Сна, минут Тоннеля и 10-минутных тактов Ядра. Внутри инициативы мастер работает с режиссёрским циклом; к пути возвращается, когда реально закончился соответствующий временной отрезок.

## Совместимость

Локальное состояние из v144 и v142 автоматически переносится в формат v145.
