# v146 · Метки, состав противников и события DM Toolkit

DM Toolkit дополнен рабочими контролами для Меток Узора, полного состава встречи и событий Стены.

## Метки участников

- У каждого участника появился выпадающий список всех 6 Меток Узора.
- После добавления Метка отображается отдельным маркером и сразу показывает полный игровой эффект.
- Метку можно удалить одним нажатием.
- Прочие состояния и заметки вынесены в отдельное поле.
- Бросок Метки в окне событий автоматически добавляет результат случайному участнику.

## Состав противников

Аудит актуального руководства подтвердил 9 существ текущего бестиария Стены:

- 3 основных противника Внешней Тени;
- 3 основных противника Внутренней Тени;
- 3 мелких существа поддержки.

Все они доступны в одном сгруппированном списке. Можно добавить несколько типов существ и задать количество каждого от 1 до 20. Сводка сцены, подготовка, ход противников и копируемый отчёт используют весь выбранный состав.

## События

- Над циклом сцены появилась контекстная ссылка к окну событий.
- Окно объясняет отдельные условия для Удара среды, Метки и Дрейфа.
- Явно указано, что события не бросаются каждый раунд.
- Добавлены полные таблицы эффектов Удара среды, Меток и Дрейфа.

## Совместимость

Данные v145, v144 и v142 автоматически преобразуются в формат v146. Текстовые Метки из старой версии распознаются и переносятся в новые элементы управления.
