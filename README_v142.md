# v142 · DM Toolkit Аномальной Стены

Добавлена отдельная мастерская вкладка `wall-dm.html` для проведения переходов и энкаунтеров в Аномальной Стене.

## Что умеет пульт

- Показывает STAB, его исходное значение и текущий диапазон на одном экране.
- Автоматически применяет обычный и тяжёлый провал маршрута, обнаруживает переход между порогами STAB и создаёт обязательные последствия.
- Перестраивает путь и памятку под семь режимов: Ореол, Окно дрейфа, Сквозь Сон, Тоннель согласованности, караван, авария в Ядре и Метод Гребня.
- Формирует чек-лист именно текущего часа, сегмента, минуты, 10-минутного цикла или боевого раунда.
- Ведёт участников, истощение и Метки Узора.
- Бросает Удар среды, Метку и локальный дрейф по утверждённым таблицам.
- Учитывает ключевые способности проводника, включая Привязки маршрута, Стабилизацию и Срыв ложного ориентира.
- Сохраняет экспедицию локально, ведёт журнал и копирует краткую сводку.

Игроковая страница `hierarchy-wall.html` получила переключатель «Правила игрока / DM Toolkit мастера».
