# v159 — восстановление регрессий Главы 6 по редакции v16

Канонические источники:

- `Дополнение к Книге Игрока 5ed по Колесу Времени_v.2.3_синхронизировано_v16_Глава_6_Регрессии_QA.md`;
- `Изменения в редакции_v16_Глава_6_Регрессии.md`;
- `QA_Глава_6_v16_Регрессии.md`.

Обновление восстанавливает согласованные правила Главы 6 без открытия нового баланс-аудита:

- «Выдающийся направляющий» снова расширяет «Одновременное плетение» до трёх Плетений и не предоставляет эту классовую черту досрочно;
- «Пламя и Пустота» содержит полную процедуру входа, разрушительного шока, оружейное ограничение бонуса Мудрости и оговорку Мастера Меча;
- «Фокусировка» позволяет бесплатно создать известное Плетение 1-го круга только один раз до короткого или продолжительного отдыха и только на базовом круге;
- реакционное Плетение «Боевого направляющего» не является Провоцированной атакой и не запускает механики нескольких Плетений;
- четыре требования приведены к термину «уровень направляющего»;
- название «Плетение без жестов» нормализовано, а его механика v15 сохранена;
- все 19 черт Дополнения помечены источником `Доп. v2.3/v16`;
- импорт ранее сохранённых NPC распознаёт прежние написания двух переименованных черт.

Сохранены без механических изменений:

- черта «Алхимик» и необычная алхимия;
- общее правило жестов Главы 9;
- «Волчий сон», «Душа двух миров» и позднее уточнение «Ходящего по снам».
