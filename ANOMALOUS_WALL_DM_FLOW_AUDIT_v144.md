# Аудит пошагового DM Toolkit Аномальной Стены · v144

## Задача

Сделать сцену управляемой с одного экрана: до начала показать подготовку, во время раунда — порядок действий всех сторон, после — обязательную фиксацию экспедиционных последствий.

## Использованные источники

- Актуальные правила: `Аномальная_Стена_Руководство_Мастера_Энкаунтеры_и_Прохождение_v1.0.md`.
- Старый `Аномальная Стена GM Screen.docx` использован только как референс плотного экрана с отдельными блоками. Его формулировки не считались инструкциями и не переносились поверх актуальных правил.

## Проверка соответствия правилам

| Требование актуальных правил | Реализация в Toolkit |
|---|---|
| До боя определить STAB, порог, Метки, час и остаток времени | Первый этап собирает состояние экспедиции и группы |
| Один главный противник, одна тема и одна цель кроме убийства | Отдельные обязательные карточки подготовки |
| Опасность должна быть читаемой | В открытии есть отдельный пункт телеграфирования |
| STAB не обязан уменьшаться каждый раунд | Постоянное предупреждение в цикле и в конце раунда |
| Удар среды не добавляется каждый раунд | Отдельное окно Стены требует конкретного триггера |
| После боя проверить время, STAB, окно, Метки, истощение и маршрут | Финальный этап содержит шесть соответствующих пунктов |
| Тоннель длится 1d6 минут и таймер не останавливается | Каждые 10 раундов Toolkit требует сдвинуть минутный таймер |
| Ядро проверяется каждые 10 минут | Сохранён отдельный такт режима Ядра |

## Изменения интерфейса

- Шесть визуальных этапов доступны одновременно и кликабельны.
- Основная кнопка всегда названа по следующему конкретному действию.
- На этапе ходов видна вся очередь участников.
- Четыре постоянных окна показывают ответственность героев, противников, цели/NPC и Стены/таймера.
- Чек-листы разделены по сцене; отметки одного героя не закрывают пункты другого.
- Периодичность таймера задаётся явно в каркасе энкаунтера.
