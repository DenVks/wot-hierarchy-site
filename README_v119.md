# v119 · Keeper Guild readability/layout patch

Цель патча: исправить визуальные проблемы на `keeper-poi-catalog.html`, где текст в карточках Гильдии Хранителей мог наезжать друг на друга и плохо читался из-за конфликтующих CSS-правил старых `.keeper-card`.

## Изменения

- Исправлен конфликт CSS: старое правило `.keeper-card span` превращало все span внутри карточек в фиксированные pill-элементы с высотой 26px. Это приводило к наложению длинного текста.
- Добавлен namespace-override для `keeper-native-page`: span внутри `.keeper-kv` теперь обычный текстовый блок без фиксированной высоты, рамки и фоновой таблетки.
- Длинные поля автоматически получают класс `keeper-kv-long` и растягиваются на всю ширину карточки.
- Средние поля получают `keeper-kv-wide`, компактные метаданные остаются компактными.
- Карточки PoI получили более читаемую структуру: отдельная шапка, код объекта, метаданные, разворот, длинные описательные поля во всю ширину.
- Улучшена адаптивность для 1120px / 760px / 520px.
- Обновлены cache-busting версии скриптов/стилей на `v=119`.
