# Аудит DM Toolkit временных аномалий · v148

## Источники

- страница правил `anomalies.html`;
- `Иерархия_Стражей_Узора_v1.0_для_игроков_Иллюстрированная.docx`;

- пакет существ `assets/monster-packs-data.js`.

## Покрытые правила

- рейтинг R1–R10 и СЛ `10 + R`;
- типы A / B / C, размеры S1–S6 и четыре режима подвижности;
- поиск узловой точки: одна минута и проверка против СЛ аномалии;
- извлечение: `1d10 + R − ранг оператора`, минимум один раунд;
- уменьшение извлечения только в конце хода оператора;
- условия канала: сознание, тот же план, дистанция до 60 футов;
- Замок Узора и к100 последствий провала;
- перемещение, опрокидывание, КД и хиты Пирамидки;
- физическая доставка заполненной Пирамидки и минутная синхронизация со Сферой;
- один бросок артефактного остатка;
- готовые существа аномалий R5–R7 Type A/B/C.

## Проверка

- JavaScript проходит синтаксическую проверку;
- в документе нет повторяющихся `id` и отсутствующих элементов, к которым обращается приложение;
- автоматический сценарий прошёл цепочку: пакет существ → известный узел → установка → проверка Ядра → пульс → волна → окончание ходов оператора → успешный Замок → заполненный заряд → доступный бросок остатка;
- проверены макеты для широкого экрана и ширины 390 px;
- состояние операции сохраняется локально в браузере.
