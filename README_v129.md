- Добавлена новая страница сайта `scream.html`: **Крик и Держащие Равновесие**.
- Полный текст игроковой главы перенесён из предоставленного HTML без сокращения игрового содержания.

- `hierarchies.html` обновлён: добавлена карточка Крика в раздел особых Иерархий.
- `assets/shared.js` обновлён: Крик добавлен в выпадающее меню «Правила».
- `assets/hierarchy-data.js` обновлён: добавлена запись `scream` с рангами и ключевыми способностями для будущих NPC-подсказок.
- `assets/styles.css` обновлён стилями страницы Крика.
