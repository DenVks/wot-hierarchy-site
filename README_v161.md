# v161 — аудит генератора NPC

Канонический источник:

- `Дополнение к Книге Игрока 5ed по Колесу Времени_v.2.3_синхронизировано_v16_Глава_6_Регрессии_QA.md`.

## Плетения

- все 93 Плетения автоматически сопоставлены с канонической таблицей v16: названия, базовые круги и Таланты совпадают без расхождений;
- максимальный доступный круг Дичка теперь берётся из его собственной ускоренной таблицы, а не из таблицы Посвящённого;
- таблицы Посвящённого и Носителя Договора проверены отдельно;
- учтён «Скачок в силе» Аша’мана на 13-м и 17-м уровнях;
- с 7-го уровня Аша’ман видит наносящие урон Плетения до 4-го круга без соответствующего Таланта;
- Айз Седай с 7-го уровня выбирает Айя; доступ Зелёной и Жёлтой Айя к Плетениям применяется автоматически;
- для Носителя Договора показан только общий список класса и расширенный список выбранного Покровителя; выбор Талантов и Аффинитетов также ограничен списком Покровителя;
- число известных кантрипов и Плетений Носителя ограничено его таблицей развития;
- без Таланта Посвящённому доступны Плетения до 1-го круга, Дичку и Носителю Договора — до 2-го;
- количество выбираемых Талантов ограничено уровнем класса;
- обычные Таланты Плетений больше не подписываются и не экспортируются как Исключительные таланты;
- кость хитов Дичка в расчёте ОЗ исправлена с ошибочной `d8` на каноническую `d6`.

## Экипировка

Добавлена отдельная группа тканевой защитной одежды:

- одежда ашамана / Айз Седай — КД 11 + ЛОВ;
- одежда сул’дам — КД 12 + ЛОВ;
- одежда айяд — КД 13 + ЛОВ.

Эта одежда повышает КД, но по правилам v16 не считается доспехом и не включает эффекты, требующие ношения доспеха.

## Дополнительные черты

- рядом с выбором черт показывается, какие пункты уровневого роста характеристик не добавлены;
- Мастер подтверждает расчёт отдельным флажком;
- без подтверждения NPC с дополнительными чертами нельзя сохранить;
- если доступных пунктов уровневого роста недостаточно, генератор показывает ошибку.

## Сохранение NPC

- кнопка «Сохранить в список NPC» явно добавляет карточку в постоянный пользовательский список текущего браузера;
- добавлена прямая ссылка «Открыть NPC / Бой»;
- добавлено скачивание JSON для переноса на другой компьютер или последующего включения в общую базу сайта;
- в боевой карточке обычные Таланты и Аффинитеты отображаются во вкладке Плетений.
