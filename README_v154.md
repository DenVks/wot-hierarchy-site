# Версия 154 · Управляемое применение Иерархий к NPC

## Что изменено

- Автоматическое распределение ранговых характеристик заменено явным выбором ГМ для каждого полученного ранга.
- Для правил «две разные характеристики» интерфейс не допускает повтор одного показателя внутри рангового пакета.
- Для Иерархии Крика учитывается общий предел +6 к одной характеристике от Иерархии.
- Для Крика добавлены выбор Ловкости или Мудрости для инициативы, результат «Счёта витков» и состояние настроенного кварцевого заряда.
- Для Единой Воли Шары добавлен явный вариант Сосуда V ранга; выбор Ш'ботай-воителя синхронизируется с Путём Воина.
- Для VI ранга Иерархии Хрустального Трона разделены предел 24 обычного персонажа/NPC и предел 26 уникального NPC.
- В финальной проверке появился блок «до → после»: характеристики, ОЗ, КД, скорость и инициатива показаны до применения Иерархии и после неё.
- Сохранённый пользовательский NPC теперь содержит исходные настройки генератора и версию базы. Его можно загрузить и пересчитать по актуальным правилам.
- Исправлено отображение названия атаки в финальной карточке.

## Проверки

- Единая база: 7 Иерархий, 43 ранга, 110 полных записей способностей, ошибок целостности нет.
- Автоматическим сценарием проверены Единство V, Крик VIII с зарядом и без заряда, оба предела Хрустального Трона VI и ветвь Воина Шары V.
- Изменённые JavaScript-файлы проходят синтаксическую проверку.
