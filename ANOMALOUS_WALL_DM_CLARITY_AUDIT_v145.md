# Аудит ясности DM Toolkit Аномальной Стены · v145

## Выявленная проблема

Пункты подготовки показывали выбранные значения, но не объясняли действие мастера. Одновременно блок «Маршрут» и боковое окно «Режим перехода» представляли один механический слой в двух местах.

## Решение

### Подготовка сцены

Для каждого пункта добавлены:

- вопрос, на который мастер должен ответить;
- конкретное действие;
- причина, почему решение нужно принять до инициативы;
- текущий выбранный пример из каркаса энкаунтера.

### Путь экспедиции

Блок оставлен, потому что он обслуживает отдельные правила времени и перемещения:

- часовые проверки Ореола;
- шесть сегментов Окна дрейфа;
- три этапа перехода Сквозь Сон;
- минуты Тоннеля;
- 10-минутные такты Ядра;
- единственную пару проверок Метода Гребня.

Он явно отделён от инициативы и снабжён последовательностью из трёх действий.

### Удалённое дублирование

Окно «Режим перехода» удалено. Динамическая проверка текущего отрезка встроена в нижнюю часть блока пути. В результате выбор типа перехода, линия прогресса, кнопки результата и объяснение периодичности находятся в одном месте.

## Проверка

- JavaScript прошёл синтаксическую проверку.
- HTML не содержит повторяющихся идентификаторов.
- Экран визуально проверен при ширине 1440 пикселей.
- Подключения CSS и JS обновлены до v145.
