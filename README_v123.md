# v123 · NPC42 affinity slot/damage recalculation patch

Патч исправляет NPC42 после проверки правила аффинитетов и ангриала.

Основные изменения:

1. Для Селайн Ко'таллен явно применены аффинитеты Огонь и Воздух.
2. Для плетений указаны требуемые ячейки после снижения от аффинитета.
3. Урон пересчитан по правилу: каждый совпавший поток повышает урон/эффект на 1 уровень.
4. Ангриал ур.5 добавляет +5 кубиков типа урона самого атакующего плетения.
5. Огненные стрелы исправлены на d8, а не d6.
6. Обновлён cache-busting в dm-npc.html до v123.
