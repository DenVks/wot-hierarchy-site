# v131 — Crystal Throne v1.2 full replacement patch

Патч заменяет описание Иерархии Хрустального Трона на исправленную редакцию v1.2 и синхронизирует основные места сайта, где используется механика Трона.

## Изменено

- `throne.html` полностью заменён на нативную страницу сайта с полным текстом источника без сокращения основного игрового содержания.
- Изображения HT перенесены в `assets/hierarchies/crystal-throne/` и подключены как обычные assets.
- `hierarchies.html` обновлён в обзорном разделе Иерархий.
- `epoch.html` и `index.html` обновлены в кратких описаниях Хрустального Трона.
- `assets/hierarchy-data.js` обновлён под редакцию v1.2: шесть рангов, Имперская СЛ, Холодная решимость, Аура Страха, Госпожа дамане, Имперская плоть, Голос Императрицы, Властитель судьбы и Легендарная регенерация.
- `assets/npc-rules-data.js` синхронизирован с новой таблицей рангов.
- `assets/npc-data.js` получил обновлённые видимые описания способностей Трона и предупреждения о необходимости отдельной ревизии NPC, использующих Хрустальный Трон.
- `dm-npc.html` обновлён по cache-busting для `npc-data.js`, `npc-rules-data.js`, `hierarchy-data.js`.

## Важно

Числовая ревизия NPC Хрустального Трона не выполнялась автоматически. После v131 требуется отдельный аудит NPC 1, 4, 32, 33 и 42, особенно NPC42, потому что новая редакция задаёт для Ранга IV направляющего +4 к атакам плетениями, +12 кубиков урона и дальность/область ×3, а одинаковые эффекты с ангриалом не складываются.
