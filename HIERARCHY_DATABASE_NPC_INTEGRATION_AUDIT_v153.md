# Аудит интеграции базы Иерархий · v153

## Результат

Сайт использует один клиентский объект `WOT_HIERARCHY_DB` для справочных описаний, механических рангов, сравнения и генерации NPC. Серверная БД не требуется: данные публикуются вместе со статическим сайтом на GitHub Pages.

## Разделение механик

- `statPoints` — накопительный пакет повышения характеристик.
- Параметры текущего ранга — итоговый профиль и не складываются между рангами.
- Именные способности наследуются по минимальному доступному рангу.
- Для Шары отдельно учитываются Путь Айяд и Путь Воина.
- Бонусы направляющих не применяются NPC, который не способен направлять.
- У Крика бонус инициативы помечен как результат проверки «Счёт витков», а устойчивость не подменяет бонус ко всем спасброскам.

## Исправленные расхождения

- Единство: вместо устаревших II–IV внесены актуальные I–V.
- Единство: бонус к СЛ направляющего исправлен на +2/+4/+6/+7.
- Аномальная Стена: вместо сокращённых II–V используются I–VIII.
- Генератор больше не ограничивает все Иерархии общим списком I–V.
- Множитель Костей Хитов больше не умножает вклад Телосложения.

## Файлы

- `assets/hierarchy-mechanics.js` — нормализованные механические профили и проверка целостности.
- `assets/hierarchy-data.js`, `assets/hierarchy-wall-data.js` — полные справочные записи и способности.
- `assets/npc-generator.js` — применение рангов к NPC.
- `assets/hierarchy-compare.js` — сравнение двух выбранных профилей.
