Гильдия Хранителей · Каталог PoI R7–R10 и археонаходок

Фар Мэддинг · 270 ПБ · зоны после аномалий, гибридные объекты и археологические находки · радиус 2000 миль
Важно. Чистые археологические объекты не имеют рейтинга аномалии R. Они помечены как AR · археонаходка и используют шкалу АРХ-7/АРХ-8: это уровень опасности раскопок, а не остаточная аномальность.

Аномальные рейтинги
R7–R10
Используются только для AS/HY/OP. Базовая СЛ = 10 + R, если карточка не задаёт отдельную проверку.
Археологическая опасность
АРХ-7 / АРХ-8
Используется только для AR. Отражает обрушения, ловушки, древние механизмы, пыль, культурные запреты и сложность извлечения.
Фильтр. Выберите кольцо поиска. Тег R означает аномальную опасность; тег АРХ — археологическую опасность.
Базовое правило. Для AS/HY/OP: R7 = СЛ 17, R8 = СЛ 18, R9 = СЛ 19, R10 = СЛ 20. Для AR используется АРХ-уровень: он задаёт СЛ работ и опасностей раскопок, но не считается рейтингом аномалии.

Полевой протокол
Разделение R и АРХ
Запрещено писать R-рейтинг у чистых археонаходок. В отчёте используется строка: «Класс AR, археологическая опасность АРХ-N».
Полевой протокол
Для AS/HY/OP
R-рейтинг означает активную или остаточную аномальную природу. Формула по умолчанию: СЛ = 10 + R.
Полевой протокол
Для AR
АРХ-уровень не повышает шанс аномального артефакта и не считается аномальной средой. Он используется для сложности доступа, извлечения и физической безопасности.
Полевой протокол
Журнал трёх версий
Для AR журнал нужен для сверки находок; для R-зон — для выявления искажения памяти, пространства или времени.
Шаблоны миссий. Для AR-миссий цель обычно — картирование, консервация или извлечение; для R-миссий — разведка, стабилизация, пробы среды или карантин.
