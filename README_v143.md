# v143 · Объединение разделов Аномальной Стены

Устаревшая страница `wall.html` больше не поддерживается как отдельная копия правил.

## Изменено

- Полный канонический материал остаётся на `hierarchy-wall.html`.
- Старый адрес `wall.html` автоматически переводит в главу `hierarchy-wall.html#p1`.
- Все ссылки «Стена» в меню сайта теперь сразу ведут в эту главу.
- Старая карточка «Аномальная Стена» на главной заменена карточкой нового `DM Toolkit Стены`.
- Старый адрес сохранён ради закладок и внешних ссылок.

Таким образом, правила больше не существуют в двух расходящихся копиях: игроковый справочник является единственным источником, а мастерский пульт использует его механику в рабочем формате.
